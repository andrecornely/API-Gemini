Gemini API com Java

Projeto desenvolvido em Java com o objetivo de praticar a integração de uma aplicação com a Google Gemini API.

🛠️ Tecnologias
Java
Gemini API
HTTP Client
JSON
API REST
📚 Sobre

Pratiquei o consumo de uma API de inteligência artificial utilizando Java, realizando uma requisição HTTP para o Gemini e recebendo uma resposta gerada pelo modelo.

O projeto foi desenvolvido como exercício prático para entender os conceitos básicos de APIs, requisições HTTP e integração com serviços de IA.
